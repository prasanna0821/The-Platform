# Vistaar / The Platform

The LRS FY27-30 deck for the banca platform, as one self-contained HTML file (34 slides, four films embedded). GitHub does not accept files over 100 MB in the repository itself, so the file is attached to a release:

**Download the latest deck:** https://github.com/prasanna0821/The-Platform/releases/latest

Open the downloaded `The_Platform_Standalone.html` in Chrome or Edge. Arrow keys move between slides, N opens the speaker notes, the slide counter opens the index. It plays from any folder with nothing else beside it.

Editions
- deck-2026-09-16: 34 slides; outcome-led run (frame, five outcome slides, sequence and decisions, definitions) ahead of the year-by-year appendix; placeholders for baselines, targets, Finance fields, owner and dates.
- deck-2026-09-15: 26 slides; FY27 block (web portal, this year) plus the three LRS years; films FY27 (2:21), FY28 (2:17), FY29 (2:24), FY30 (2:06).
